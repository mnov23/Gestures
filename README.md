# Gestures - Android Sample Project

A simple Android application demonstrating gesture detection and handling techniques.

## Project Overview

This project was originally created as an assignment for **FIT2081 Mobile Application Development** at **Monash University**. I've made some modifications and improvements to showcase my Android development skills, sensor integration, and understanding of gesture recognition patterns to potential recruiters. The original code was written in the pre-LLM era without AI assistance, and I successfully submitted this assignment and passed the unit with flying colors.

The app demonstrates various touch gestures including single-touch, multi-touch, and custom gesture recognition using Android's built-in gesture detection APIs. Built in Java using the provider pattern architecture, the application allows users to create and manipulate shapes on screen through intuitive gesture interactions.

## Installation

### Download APK
Ready-to-install APK files will be provided in the releases section.
You should use "app-universa-debug.apk" in app/releases/

1. Download the APK file to your Android device
2. Enable "Install from Unknown Sources" in Settings > Security  
3. Tap the APK file to install
4. Open the app and play around.

### Build from Source
If you're a developer and want to poke around the code or modify it, just grab the repo and open it in Android Studio. You know the drill.[¹](app/src/main/res/layout/CENTER_DIV.md)
